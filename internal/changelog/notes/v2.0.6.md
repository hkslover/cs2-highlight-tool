## 中文

### 新增

- 新增 Steam 官方匹配导入：获取 Steam 最近的官方比赛，也支持通过分享码导入
- 启动页支持切换 HLAE 版本通道，可为旧版 CS2 选择对应的 HLAE 版本
- 录制设置新增"动态模糊"（HLAE 采样器），开启后画面更顺滑，录制耗时会相应增加
- 录制设置新增"防闪光强度"滑动条，可按百分比削弱闪光弹效果
- 录制设置新增"仅显示当前 POV 玩家击杀信息"，每个录制视角只保留该玩家相关的击杀提示
- 录制设置新增"隐藏聊天消息"，默认开启
- 录制时自动隐藏比赛结束动画与结算画面
- 调试模式新增独立调试工作台：自定义启动参数与启动指令、Demo 播放、控制台快捷指令和手动录制

### 优化

- 录制时加载软件水印
- 更新了第一人称 POV HUD VPK
- 剪辑页改为整页滚动
- 受害者视角快节奏剪辑不再在视频旁生成额外的元数据文件
- 禁止界面文字被误选中和原生拖拽

### 修复

- 修复 POV 雷达在切换视角后未生效的问题，现在每次切换视角后都会重新开启并预留预热时间
- 修复关闭"屏蔽玩家头像"后头像无法恢复的问题


## English

### Added

- Steam official match import: fetch your recent official Steam matches, or import by share code
- Switch HLAE version channels on the startup page to pick an HLAE build that matches an older CS2
- New "Motion blur" recording option (HLAE sampler) for smoother footage; recording takes longer when enabled
- New "Flash suppression strength" slider that reduces flashbang effects by percentage
- New "Only show the current POV player's kill feed" option, keeping only kill notices involving the player in each recorded view
- New "Hide chat messages" recording option, enabled by default
- The end-of-match animation and scoreboard are automatically hidden during recording
- Debug mode adds a standalone debug workbench: custom launch arguments and startup commands, demo playback, console quick commands, and manual recording

### Improved

- The tool's watermark is loaded during recording
- Updated the first-person POV HUD
- The edit page now scrolls as a whole page
- Opponent fast edit no longer writes extra metadata files next to videos
- Prevented accidental UI text selection and native dragging

### Fixed

- POV radar not taking effect after a camera switch; it is now re-enabled after every switch with a warm-up period
- Player avatars not coming back after turning off "Hide player avatars"
