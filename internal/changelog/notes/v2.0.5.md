## 中文

### 新增

- 片段页新增击杀筛选：武器、命中部位、多杀/残局等击杀状态、击杀距离
- 录制设置新增"屏蔽玩家头像"
- 剪辑页新增"受害者视角快节奏剪辑"
- 剪辑源面板支持按回合导入，素材列表支持批量移除已选素材
- 顶部横幅广告改为图片卡片，并新增进入主界面时的弹窗广告

### 优化

- 前端 UI 调整优化
- 击杀图标改为按武器确定的映射，缺少图标时以文字降级显示
- 片段页交互优化：单击选择击杀、连点防抖、素材快捷删除
- 组件下载改为多地址并行竞速，先成功的地址胜出
- 启动探测完成后自动刷新实际生效的编码器信息

### 修复

- 修复 4:3 录制出现左右黑边、以及转场合并后画面变形的问题
- 修复最后一回合录制越过赛后结算面板、缺失视角无法补录的问题
- 修复中途重连丢失 demo_done 导致制作队列卡死、无法继续录制的问题
- 修复制作中断后残留环境备份未正确恢复的问题
- 修复制作诊断日志在 Windows 文本查看器中乱码的问题
- 修复组件安装、Demo 导入、剪辑合成中断后残留半成品或覆盖既有产出的问题
- 修复若干并发与生命周期问题：取消下载后仍继续安装、同一 Demo 并发导入重复下载、工作目录重置与制作会话竞态等


## English

### Added

- Kill filtering on the clip page: weapon, hit group, kill context (multi-kill, clutch), and distance
- New "Hide player avatars" recording toggle
- Opponent fast edit mode on the edit page
- Per-round import in the edit source panel, and a bulk "remove selected materials" action
- The top banner now uses image cards, plus a new main-entry popup ad

### Improved

- Frontend UI adjustments and polish
- Weapon icons now come from a deterministic weapon mapping, with a text fallback
- Clip page interactions: single-click selection, rapid-click debounce, quick deletion
- Component downloads now race their addresses in parallel and keep the first success
- The effective encoder refreshes automatically once the startup probe completes

### Fixed

- Side black bars on 4:3 recordings, and distorted output when merging clips with transitions
- Recordings overshooting the post-match win panel, and missing views that could not be re-recorded
- A production queue hang after a mid-demo reconnect lost demo_done, which blocked later recordings
- Leftover environment backups not being restored after an interrupted production
- Produce diagnostics showing mojibake in Windows text viewers
- Half-written output or overwritten results when a component install, demo import, or edit compose was interrupted
- Several concurrency and lifecycle issues: a cancelled download still installing, duplicate downloads of the same demo, and workspace reset racing the production session
