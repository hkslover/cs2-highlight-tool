# 01：调试导航与页面骨架

前置：阅读 [README](README.md) 和根/前端规则。范围只包含入口、页面和临时 UI 草稿；此步不新增可执行的启动/录制假接口。

## 实施

1. `MainApp.vue` 使用已有 `useDebugSettings().debugEnabled`，四步之后条件渲染第五步「调试」。步骤映射和路由列表同步增加 `/debug`，当前高亮为 5；普通模式仍是四步。
2. `router.ts` 新增 `/debug`，关闭 debug 时直接访问 hash 路由应返回 `/import`，不展示调试页面。保持现有 `/settings` 的导航布局。
3. 新增 `features/debug/pages/DebugPage.vue`。按启动、连接/会话状态、Demo 播放、快捷设置、自定义命令、手动录制及结果六块布局，窗口 `920×680` 内纵向滚动，避免主要按钮被遮挡。
4. 启动区提供插件模式选择、POV HUD/品牌/雷达开关、分辨率；雷达在无插件模式禁用。运行前可编辑，运行后把 VPK/分辨率标为重启后生效。
5. 自定义命令使用多行文本输入与显式发送按钮，保留内容便于修改重发。组合命令用分号；不引入终端模拟器。
6. Demo 区显示导入页当前 `selectedEntry.file_name/file_path`，可返回导入页改变选择。无选择时显示空态，不要求击杀或 full_round_pov。
7. 在后续 API 尚未完成前，操作按钮禁用并说明待接入；不要输出假的“已连接/已录制”。中文文案写 `zh-CN.json`。

## 验收与交接

- 未激活 debug 四步；点击品牌 10 次后五步；切换步骤与 `/debug` 高亮正确。
- 设置页既有 debug 项仍可用。进入/离开调试页不改变正式设置，不关闭游戏。
- 骨架构建执行 `cd frontend && npm run build`；若增加领域/适配层逻辑，同时 `npm test`。
- 更新前端路由规则。交接说明下一步接入的按钮和组件位置，不提前实现 02。
